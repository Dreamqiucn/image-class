## 今天的目标

把 Day 78（`Conv2d` 形状对齐）和 Day 79（`BatchNorm2d`）真正拼成一次**残差连接 `ReLU(F(x) + x)`**（明天 Day 81 再把它正式封装成 `nn.Module` 类）。今天在 1 个精简函数 `day80()` 里看清两件事：

1. 标准残差块里 `Conv2d`、`BatchNorm2d`、`ReLU` 和 `+ x` 的**准确先后顺序**；
2. 为什么第二个 `ReLU` 要放在 **`+ x` 之后**，而不是放在主分支末尾。

## 核心结构（特别留意第二个 `ReLU` 的位置）

```text
输入 x ───────────────────────────────┐  (跳跃分支：原样保留 x，别被主分支覆盖)
  │                                   │
  ▼                                   │
主分支 F(x):                          │
  Conv2d(16, 16, 3, padding=1, bias=False)
  BatchNorm2d(16)                     │
  ReLU()                              │
  Conv2d(16, 16, 3, padding=1, bias=False)
  BatchNorm2d(16)                     │
  │                                   │
  └──────────────► ( + ) ◄────────────┘  (fx + x 逐元素相加)
                     │
                     ▼
                   ReLU()               (最后再激活！)
                     │
                     ▼
                   输出 out
```

**为什么主分支末尾（第二个 `BN` 之后）先不做 `ReLU`？**
因为如果先做了 `ReLU`，`F(x)` 就永远 `>= 0`，主分支就只能把 `x` 往大调、永远没法把不需要的像素值往下减。把第二个 `ReLU` 放在 `fx + x` 之后，主分支就能自由输出正数或负数来对 `x` 做双向微调。

## 精简实验（1 个 `day80()` 函数）

继续在 `scripts/torch_week12.py` 里新增 `day80()`（不用拆多个小函数），用小张量完成下面几步：

1. **定义主分支 `main_path` 与输入 `x`**：
   - `x = torch.randn(2, 16, 56, 56)`；
   - 用 `nn.Sequential(...)` 搭上面图里的 5 层主分支（两层 `Conv2d(16, 16, 3, padding=1, bias=False)` + 两个 `BatchNorm2d(16)` + 中间 1 个 `ReLU()`）。
2. **前向计算并保留原始 `x`**：
   - 算 `fx = main_path(x)`（注意用新变量名 `fx`，千万不要写成 `x = main_path(x)` 把原输入覆盖掉）；
   - 再算 `out = torch.relu(fx + x)`；
   - 打印 `x.shape`、`fx.shape`、`out.shape`，并顺手打印 `fx.min()` 和 `fx.max()`（确认 `fx` 里既有正数也有负数，能双向调整 `x`）。
3. **2 行直觉验证（主分支归零时的效果）**：
   - 打印 `(torch.relu(fx * 0 + x) == torch.relu(x)).all()`（或对比 `fx * 0` 与 `fx * 0 + x`），亲眼确认当主分支学成“不做修改（输出 0）”时，靠跳跃分支 `x` 照样能把特征完好无损地传下去。
