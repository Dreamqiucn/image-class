## 图片的三个轴

使用 Pillow 将图片转换成 RGB，再用 np.array 转成数组。普通 RGB 图片的数组形状为 (H, W, 3)，分别表示高度、宽度和红绿蓝三个通道。Pillow 的 image.size 则是 (W, H)，顺序不同。

- a[y, x]：第 y 行、第 x 列像素的三个通道值，顺序为 R、G、B。
- a[y, x, 0]：这个像素的红色通道值。
- a[:, :, 0]：整张图片的红色通道，形状为 (H, W)。

索引从 0 开始。原图可能是灰度、调色板或带透明通道的图，今天统一转成 RGB 是为了固定练习输入格式；不表示以后可以忽略所有透明图片的处理策略。

```python
from pathlib import Path
from PIL import Image
import numpy as np

path = Path("填写一张实际图片的路径")
with Image.open(path) as image:
    rgb = image.convert("RGB")
    a = np.array(rgb)
```
