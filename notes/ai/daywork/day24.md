## 目标

理解元素数量不变时如何改变数组形状，区分 reshape 与转置，并能按照指定轴顺序转换一个三维数组。

## 1. reshape：按新形状组织元素

```python
import numpy as np

x = np.array([1, 2, 3, 4, 5, 6])
a = x.reshape(2, 3)
print(a)
# [[1 2 3]
#  [4 5 6]]
print(a.shape) # (2, 3)
print(x.shape) # (6,)，reshape 不会原地改变 x 的形状
```

默认按最后一轴最快变化的顺序读写，二维可先理解为逐行读、逐行填。新形状各轴长度的乘积必须等于原数组 size。六个元素可以变成 (2,3)、(3,2)、(1,6)，不能变成 (2,4)，否则报 ValueError。接收返回结果或打印返回结果，单独执行 x.reshape(...) 不会把 x 重新绑定为新形状。

```python
print(x.reshape(3, -1).shape) # (3, 2)
print(a.reshape(-1))        # [1 2 3 4 5 6]
```

-1 表示根据元素总数和其他轴长度推算这一轴，不是负下标；一次最多指定一个 -1。

## 2. 二维转置：交换行列轴

```python
print(a.T)
# [[1 4]
#  [2 5]
#  [3 6]]
print(a.T.shape) # (3, 2)
print(a.transpose(1, 0)) # 与这个二维数组的 a.T 相同
```

原位置 a[i,j] 对应转置后的 a.T[j,i]。T 是属性，不加括号；transpose 是方法，需要括号。一维数组 x.T 仍是一维 (6,)，要得到二维列形状可使用 x.reshape(-1,1)。

```python
print(a.reshape(3, 2))
# [[1 2]
#  [3 4]
#  [5 6]]
```

这个结果与 a.T 的 shape 同为 (3,2)，但元素位置不同。reshape 默认按原逐行顺序重新分组，转置则按轴交换位置，不能只看 shape 判断结果相同。

## 3. 轴顺序

shape 中从左到右的轴编号为 0、1、2……。二维 shape=(2,3) 的轴 0 对应行方向，轴 1 对应列方向；三维 shape=(2,3,4) 则有三个轴，其长度分别为 2、3、4。

```python
c = np.arange(24).reshape(2, 3, 4)
d = c.transpose(2, 0, 1)
print(c.shape) # (2, 3, 4)
print(d.shape) # (4, 2, 3)
print(c[1, 2, 3], d[3, 1, 2]) # 23 23
```

np.arange(24) 创建从 0 到 23 的整数数组，仅用于方便构造示例。transpose(2,0,1) 的意思是新数组按“原轴2、原轴0、原轴1”排列，不是把轴长度设置成 2、0、1；每个原轴恰好出现一次。

图片若采用 (高,宽,通道) 的 HWC 排列，transpose(2,0,1) 会变为 (通道,高,宽) 的 CHW 排列。这里只演示数组，不要求今天读图片。一维之外，T 默认反转全部轴顺序，因此三维的 T 对应 (2,1,0)，不能直接代替 (2,0,1)。

reshape 与转置的返回结果可能共享原数组数据，不要默认它们都是独立副本；本日以读取比较为主，不展开内存细节。
