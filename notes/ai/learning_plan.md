## 开发环境方案

Windows 是这个项目的主开发与训练环境，方便直接使用 NVIDIA GPU；Mac 可以阅读、记笔记，或完成不需要 GPU 的代码工作。尽量避免每天在两台电脑之间来回配置环境。

- 编辑器优先沿用我熟悉的工具。
- 环境管理在 Conda、uv、venv 中选一种即可。先检查我已有环境，已有可用方案就沿用，不要为追求统一重新配置。
  - 2026-10-09 已决定并执行：Windows 笔记本上 Python 为 3.12.10，Git 为 2.47.1，**未安装 conda 和 uv**，因此选用 Python 自带的 venv，不再安装 conda 或 uv。
  - 项目虚拟环境位于仓库根目录 `.venv`，创建命令为 `py -3.12 -m venv .venv`。建议用 `py` 而不是 `python`，因为 `where python` 里存在 Windows 商店的占位程序 `WindowsApps\python.exe`，误用会导致创建失败。
- 初期优先 Windows 原生开发。有具体问题再考虑 WSL，不要求先学习 Docker、远程开发或复杂部署。
- PyTorch 与 NVIDIA 驱动的安装以当时的官方文档为准，不照搬旧视频中的版本组合。安装成功后，除了检查 GPU 可用性，还应运行一次小规模前向、反向计算。
  - 本机显卡为 RTX 5070 Ti Laptop，选择轮子前核对架构兼容性。装好后先验证 `torch.cuda.is_available()`，再做前向与反向计算；出现内核不兼容错误时检查轮子与架构支持。
- 两台电脑用 Git 同步代码，各自维护环境。不要同步虚拟环境目录，也不要把大型数据集和模型权重默认提交进 Git。
- 设备型号不等于训练速度保证；先用小批次、小数据验证，再决定 batch size 和训练规模。
