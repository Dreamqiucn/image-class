## 本日问题与解释

### 1. try 放在哪里，except 是否解释错误，raise 是否调用解释错误的函数？

try 包住希望处理异常的操作，可以在主程序或函数里；except 与 try 对齐并紧随其后，捕获匹配的异常并执行自己写的处理逻辑，不自动生成解释。raise 是语句：异常类加括号创建异常对象，raise 将其抛出，跳过当前正常流程。函数内部的异常可沿调用链传到外面的 try/except。处理后不会自动重做失败语句。

### 2. raise dirnot 与 except dirnot 为什么两次 NameError？

dirnot 没有定义，不是任意命名即可使用的内置异常。抛出时找不到它，处理原错误时再次引用它又报 NameError。可以用已定义的 ValueError 等类型；as 后的 Error 是接收异常对象的普通变量名，与异常类型名不同。

### 3. 有哪些异常，如何自己定义？

讲解 ValueError、TypeError、NameError、AttributeError、IndexError、KeyError、ZeroDivisionError、FileNotFoundError、NotADirectoryError 和 PermissionError 的典型情形。OSError 是后三种文件相关异常的父类，捕获父类也能接住这些子类。自定义可写 class DirNotError(Exception): pass，先定义，再 raise DirNotError(...)，用对应 except 捕获。Error 结尾是命名习惯，不是语言强制要求。自定义异常只作讲解，没有加入实际脚本。

### 4. 改为 OSError 后为什么处理异常时仍出错？

读取实际代码发现 print("请重新输入" + Error)。Error 是异常对象，不能直接与字符串相加。可以 str(Error)、f 字符串或 print 的多个参数。另指出应先 exists 再 is_dir，否则不存在路径也先被判为非目录；Path("。") 是名为中文句号的路径，当前目录应使用 Path(".")。

### 5. 什么时候用加号、逗号？

字符串加号先连接字符串，两侧需是字符串；数字加号是加法。print 的逗号分隔多个参数，能直接接收不同类型，默认以空格分隔，可用 sep="" 去掉间隔。f 字符串适合把变量嵌在指定位置。

### 6. input 的提示如何换行？

字符串里的 \n 控制换行，例如 input(f"{Error}\n请重新输入路径：")。f 负责表达式插值，不负责换行；input 的返回值需要 Path(...) 转为路径对象。

### 7. except 重新输入后，如何再次执行主体？

将主体放入 while True；成功后 break；except 更新 p 后下一轮重试。首次输入与配置应放循环外，避免每轮覆盖新路径。if __name__ == "__main__" 是条件判断而不是可直接调用的函数。提示文本本身不会重新输入，也不会自动重试。

### 8. 还有什么方法？

可将主体封装成 main()，except 中 return main() 递归重新询问。每次递归增加调用层，反复失败太多可能 RecursionError，持续输入重试更适合 while。此处为示例讲解，实际脚本最终使用循环。
