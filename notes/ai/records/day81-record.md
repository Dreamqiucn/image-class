# Day 81：封装同通道、同尺寸的 BasicBlock

日期：2026-11-28。用户在 `scripts/torch_week12.py` 写了 `BasicBlock`，在 `__init__` 接收通道数并创建卷积和 BN，在 `forward(self, x)` 接收当前批次。主分支的结果与输入相加后经过 ReLU。

Windows Conda Python 实际运行成功。输入由代码生成，形状为 `(2, 16, 56, 56)`，脚本打印输出 `torch.Size([2, 16, 56, 56])`。

当日讨论了两种不同的变化。同一通道数的不同批次可以共用一块的权重。处理固定但不同的通道数，可以用同一个类分别创建块。单次前向中改变输入和输出的通道数时，需要把跳跃分支变换到与主分支相同的形状，这是 Day 82 的内容。
