## 今日问题与解释

### 1. 创建 FolderScanner 时传几个参数，只传一个会怎样？

对 __init__(self, root, excluded) 的定义，调用类时提供 root 和 excluded 两个参数，self 由 Python 自动传入。缺少必需参数时抛 TypeError，__init__ 的方法体不会执行；不是只给 root 保存值后成功创建对象。设置默认值后才能省略对应参数。本次用户实际命名为 p，原理相同。

### 2. from pathlib import Path 中哪个范畴更大？

pathlib 是处理路径的模块，Path 是该模块提供的类。from pathlib import Path 表示从模块导入这个类，Path 的 P 需大写。直接导入 Path 后写 Path(...)；只 import pathlib 时写 pathlib.Path(...)。

### 3. 类像局部环境吗，__init__ 何时执行，self 必须这样命名吗？

用户复盘回答把类理解成局部环境，认为初始化在创建类时执行，认为左边是类属性、右边是传入参数。

解释并纠正：Folderscanner 是类，scanner_a 是实例对象；__init__ 在实例创建时执行，不是定义类时执行。self.p 是当前对象属性，p 是接收的参数。self 指当前实例，不是整个类；self 只是惯用参数名，不是保留关键字，可以换成 obj 等名称，保持函数体对应名称一致，通常沿用 self。类可以组织相关数据和操作，但不应等同于函数局部作用域。
